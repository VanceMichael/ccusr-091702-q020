# 青少年书目审议档案库

本服务用于候选书目、匿名评议、利益回避和发布更正。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：征集版本、候选快照、评审人、利益关系、匿名意见、复核轮次、发布版本、访问凭证。

截止后候选快照不可变；存在利益冲突时自动回避；揭盲前不得侧漏身份；发布后的变化通过关联新版本表达。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/reading_review.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
